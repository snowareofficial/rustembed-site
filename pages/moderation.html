可以先下架、后说明的情形

管理员可先行下架（把文章 draft: true 或撤下链接），再与作者沟通，仅限：

  1. 涉及未授权转载、版权投诉；
  2. 泄露密钥、个人信息、内部资料；
  3. 内容存在严重事实错误且可能误导他人；
  4. 附件含恶意文件或不可控风险。

下架时管理员必须在 PR / 群里写明：哪篇、为什么、谁决定的。

作者主动下架

作者本人可随时要求下架自己的文章：提 PR 改 draft: true，或在群里告知任一管理员。 无需理由，管理员不得拖延；下架后如需恢复，作者说一声即可。

申诉

  • 申诉渠道：群里 @ 任意管理员，或提 Issue（标签 制度建议）；
  • 时限：管理员2 个工作日内回应；
  • 处理：由未参与原决定的管理员复核；分歧时按「角色与权限制度」的决策方式处理（两名以上管理员同意，必要时群主裁决）；
  • 结果与理由必须公开写明，不得只回复结论。

记录

每次下架与申诉都在 Issue 里留档：时间、文章、理由、决定人、结果。这些记录不删除，供以后核对。
