进阶

  • 系列文章：front matter 里写 series: {id, title, order}，会自动进侧栏树并生成上一章/下一章
  • 视频：也可以写在 front matter 的 video 字段
  • 附件：图片入库（同目录 assets/），其余外链，写在 front matter 的 attachments 里
  • 内联角色：文字、术语、公式、文字 在 Markdown 里同样可用
  • 字段写错会被内容契约拦下，报错形如 [E-CONTRACT-003] 缺少必填字段 summary（字符串）
  • 契约清单与字段说明见「文档 → 规范 → 内容契约」（由 content/contracts/*.sml 自动生成）

构建会校验必填字段、图片是否存在、附件类型与体积；写错会直接报错，不用自己猜。

加资源

文章用 Markdown；资源、项目、成员、互助是结构化条目，用 SML。SML 不是编程，只是「字段: 值」列表。

sml
title: "The Embedded Rust Book"
kind: book
url: "https://docs.rust-embedded.org/book/"
tags: [ rust embedded book ]
note: "官方入门书，no_std 与外设访问的基础概念都在这里。"

复制模板到 content/resources/<英文短名>.sml；引擎按目录自动套 Resource 契约，不需要写契约名。

字段表用 python engine/cli.py contracts 查看；完整模板在仓库 templates/ 与 docs/CONTRIBUTING.md。
