# 文章多语言（i18n phase 1）

> 范围：**只有文章（posts）**多语言。不翻译 UI、不改目录结构、不建 `zh/` `en/` 子目录。
> 与 hy4 的 M3（GUI 多语言）文件所有权严格分开，本文件只描述 posts 这层的实现。

## 1. 文件命名

同一目录放多个语言版本，文件名用语言后缀区分：

```
site/content/posts/<年>/<slug>/
  index.md        # zh（默认，URL 不变）
  index.en.md     # en
  index.sml       # zh 的 SML 写法
  index.en.sml    # en 的 SML 写法
```

- 正则：`^index(?:\.([a-z]{2}))?\.(md|sml)$`
- 无后缀 = zh；`index.<lang>.(md|sml)` = 对应语言。
- 语言白名单只有 **zh / en**；其它如 `index.fr.md` 在构建期直接报
  `不支持的语言` 并中断构建。
- 同一 `(年, slug, 语言)` 出现两次（典型：`index.md` + `index.zh.md`，或
  `index.en.md` + `index.en.sml`）→ 构建期报「重复了语言」并中断构建。
- `posts/**` 下的内容文件**不得是符号链接**：符号链接在扫描期报错并跳过，
  防止借软链逃逸站点目录（Windows 无权限建软链时该测试跳过）。
- 同目录 `assets/` 被所有语言版本共享（路径改写统一到 `assets/posts/<slug>/`）。

## 2. manifest 形状

每个 post 增加 `default_lang` 与 `langs`（仅多语言、或默认语言非 zh 时出现）；
**单语言 zh 文章不加这两个字段**，顶层字段保持旧形状，确保旧前端 / 搜索零变化。

```jsonc
{
  "slug": "cortex-m-bringup",
  "title": "…（zh 标题，兼容旧前端）",
  "summary": "…（zh）",
  "tags": ["…"],            // zh
  "html": "p/cortex-m-bringup.html",   // zh，URL 不变
  "words": 959,
  "default_lang": "zh",
  "langs": {
    "zh": { "html": "p/cortex-m-bringup.html", "title": "…", "summary": "…", "tags": ["…"], "words": 959 },
    "en": { "html": "p/cortex-m-bringup.en.html", "title": "…", "summary": "…", "tags": ["…"], "words": 942 }
  }
  // …其余字段不变
}
```

- 顶层 `title/summary/tags/html/words` 始终取**默认语言**（zh）的值，旧前端不加改动即可用。
- `langs.<lang>.html` 是各语言版本的相对路径（`p/<slug>.<lang>.html`）。
- `_variants`（非默认语言待写盘内容）以 `_` 前缀被过滤，不进 manifest。

## 3. 产物

- `p/<slug>.html` —— zh（默认），路径 / 内容 / 字段与旧构建完全一致。
- `p/<slug>.en.html` —— en 独立渲染，不共享正文、独立走 load2 / 契约 / 渲染 / TOC / 字数。
- 单语言文章：只产出 `p/<slug>.html`，**不**产出 `.en.html`，manifest 不含 `langs`。

## 4. 路由（前端 hash SPA）

- `#/post/<slug>` → zh（不带 `?lang=` 的行为完全不变）。
- `#/post/<slug>?lang=en` → en。
- `viewPost` 读取 slug 后的 `?lang=`；解析失败 / 不在 `langs` → **回落 `default_lang`，不做跳转**。
- 只有 `zh` / `en` 被接受；非法值（`fr` / `../x` / `javascript:` 等）一律回落 zh，
  **不接受任意 query 影响文件路径**（白名单天然拒绝）。
- 选到 variant 后，`<title>`、摘要、标签、字数、正文 `html` 全部用该语言版本；
  `document.documentElement.lang` 设为当前语言。
- 语言版本 > 1 时，标题下方显示切换器（中文 / English），点击只改 query、**保持滚动位置**
  （切换前记 `window.scrollY`，渲染后恢复）；当前语言为不可点状态。
- 所有拼 href 仍走 `lnk` / `safeUrl` 白名单；slug 来自 manifest（构建期），切换按钮
  `href` 用 `#/post/<slug>?lang=...`，不拼入未转义字段。

## 5. 限制 / 非目标（本阶段不做）

- 不翻译 UI 文案（导航 / 按钮 / 错误 / 空状态）。
- 不建 `zh/` `en/` 子目录，不改现有 URL。
- 不做 `pages` / `topics` / `weekly` / `resources` 的多语言。
- feed.xml / sitemap.xml / llms.txt 只列默认语言（search-index 同理取 zh 正文）；
  多语言索引不在本阶段范围。
- 不做静态 SEO 多语言页（当前是 hash SPA）。
- 不改 GUI（hy4 的 M3 负责）。

## 6. 安全不变量

- 语言只来自白名单 `zh / en`；`<html lang>`、链接参数、切换按钮 `href` 均不拼接未白名单值。
- 除 `lang` 外不接受任意 query 影响文件路径；`?lang=../x` 这种路径穿越被白名单拒掉。
- 不新增 `innerHTML` 拼接未转义字段，沿用现有 `esc` / `textContent` / `frag()`。

## 7. 测试

- `tests/i18n_test.py`（标准库，临时站点目录，不改真实 `site/content`）：
  - 单语言零变化：manifest 无 `langs` / `default_lang`，`p/<slug>.html` 内容不变；
  - 多语言：`p/<slug>.en.html` 生成、`langs.en` 正确、静态 `GET 200`；
  - 重复 zh / 重复 en / 符号链接逃逸 / 非法 lang 文件名 → 构建失败；
  - 顶层字段保持 zh 兼容（防回归）。
- 运行时 `?lang=` 回退（fr / `../x` / `javascript:` → 回落 zh、不越界）属 `app.js` 行为，
  **无法用纯 Python 单测**，需人工在浏览器验收：
  - 打开 `#/post/cortex-m-bringup` → 中文；
  - 打开 `#/post/cortex-m-bringup?lang=en` → 英文标题 / 摘要 / 正文；
  - 语言切换不刷新页面、不丢滚动；
  - 现有中文文章 URL / 内容不变。
