}

要点：

概念解释
签名末尾无 ;自动返回值就是表达式，免 return
末尾 ;等价 return ();，函数返回 unit
! 发散函数永不返回，可强制任何分支返回同一类型
递归没有尾调用优化（TCO）保证；大递归请用迭代
函数指针fn(i32) -> i32 是一类值，可赋给变量、传参、做返回值
函数当参数形如 F: Fn(i32) -> i32，是泛型闭包约束
函数嵌套内部函数闭包外层局部变量（闭包捕获）

struct Circle {
    x: f64,
    y: f64,
    redius: f64,
}

impl Circle {
    fn area(&self) -> f64 {
        std::f64::consts::PI * (self.redius * self.redius)
    }
    fn grow(&self, increment: f64) -> Circle {
        Circle {
            x: self.x,
            y: self.y,
            redius: self.redius + increment,
        }
    }
}

模式解构参数

rust
fn main() {
struct S { field1: char, field2: bool }
fn someFunc(S { field1: arg1, field2: arg2 }: S) {
    println!("{} {}", arg1, arg2);
}
}

参数处的模式解构是"先解构、再调用"——既能匹配，又能在签名清晰表达。
