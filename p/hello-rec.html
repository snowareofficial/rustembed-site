为什么从工具链讲起

嵌入式 Rust 的第一道坎通常不是语言，而是「怎么把东西弄进去」。这篇只走一条能跑通的路：装工具 → 连上 → 烧录 → 看日志。

下文以常见的 Cortex-M 调试探针为例，其它芯片换 target 即可。

安装

只需要一个命令：

bash
cargo install probe-rs-tools --locked
rustup target add thumbv7em-none-eabihf

装完用 probe-rs list 确认探针被识别；看不到设备先查驱动，不要先怀疑代码。

烧录与日志

进到工程目录执行：

bash
cargo run --release

若已在 .cargo/config.toml 里配好 runner，这一步会直接烧录并打开 RTT 日志。没有 RTT 时改用：

bash
probe-rs run --chip STM32F407VG target/thumbv7em-none-eabihf/release/app

工具链的复杂度是一次性成本，跑通一次之后都是复利。

常见坑

  • 探针固件过旧：升级后再试
  • 芯片被读保护：先解除保护
  • 连上了但下不进去：确认 target 三元组与芯片型号匹配
