字面量是直接写在源码里的值。Rust 通过类型后缀、下划线分隔和转义规则把字面量表达得既紧凑又自描述。

1.3.1 数字字面量

rust
fn main() {
let one_thousand     = 1e3;          // 整数字面量也允许科学计数
let ten_eight        = 10_000_000;   // 下划线任选位置，仅为可读
let typed            = 65_536u32;    // 类型后缀
let pow              = 2_i32.pow(3); // 类型后缀 + 调用方法
let byte             = b'A';         // u8 字面量
}

字面量进制前缀与下划线分隔

Rust 整数字面量支持四种进制，与"类型后缀 + 下划线"完全正交，可叠加使用：

前缀进制例
无十进制123_456
0x十六进制0x_DEAD_BEEF
0o八进制0o_755、0o_777_205_162（Unix 文件权限常用）
0b二进制0b_0110_1001_1111_0001、0b1011_0100

下划线 _ 只能出现在数字之间，前后均可自由放置，仅为可读。0o_777 等价 0o777，等于十进制 511。

rust
fn main() {
let octal  = 0o_777_205_162;       // 八进制：可执行权限掩码常用
let binary = 0b_0110_1001_1111_0001;
println!("{:o} {:b}", octal, binary);  // 用 :o / :b 重新按八/二进制打印
}

已编译运行。

latex
777205162 110100111110001

注：该文件除上述进制外，还顺带演示了宽度来自变量的格式化与 Display / Debug 双重输出（详见 1.19.2）。

1.3.2 字符串字面量

rust
fn main() {
let speech = "\"北科信链！\" amazing.\n";    // 普通转义
let accent = "th\u{e9}";                     // unicode 转义
let multi  = "this is a
   test";                                    // 真实换行（换行符也算字符）
let raw    = r"D:\DevC++\mingw64\bin";       // 原始字符串，不解析转义
let nested = r###"hello,world!"###;          // 哈希数等于 # 数量，可以嵌 #
}

字符串字面量是 &'static str：类型 = &str，生命周期 = 'static，存放在编译期常量段，不可变。需要堆上可变长字符串请用 String::from("...") / format!("...")。

1.3.3 字符字面量

rust
fn main() {
let _love = '+';
let _c1   = '\n';
let _c2   = '\x3f';      // 16 进制转义
let _c3   = '\u{7FFF}';  // 任意 unicode 码点
let _byte = b'A';        // 单引号的字节字面量是 u8，等价 65
}

常见转义字符

特殊字符Rust 中的字面量表示含义
单引号'\''输出单引号 '，用于 char 字符字面量
反斜杠'\\'输出单个反斜杠 \
换行'\n'换行符，光标移至下一行开头
制表符'\t'水平制表符，产生一段空白缩进

Rust 中所有合法字符（与字符串）转义一览：

  • \\ → 反斜杠本身 \
  • \' → 单引号 '
  • \" → 双引号 "（在 char 里其实不需要，写了也合法）
  • \n → 换行 LF
  • \r → 回车 CR
  • \t → 水平制表
  • \0 → 空字符 NUL
  • \xHH → 16 进制 ASCII（如 '\x3f'）
  • \u{7FFF} → 任意 Unicode 码点（最多 6 位 16 进制）

不要写两段反斜杠当转义：Rust 里只有 \ 是真的反斜杠；\\ 是字面量里的 \，会被解析成"反斜杠"字符一次。要让 println! 输出一个反斜杠，写 println!("\\")。

想禁用所有转义规则，用 原始字符串字面量 r"..."（见 1.3.2 节）。
