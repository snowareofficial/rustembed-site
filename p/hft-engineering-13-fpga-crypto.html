CPU → FPGA → ASIC 演进

架构特点
CPU通用 · OS/调度/中断 · μs 级 软件极限
FPGA可编程硬件 — 介于 CPU 与 ASIC 的 黄金平衡
ASIC全定制 · 最快 · 不可改 · 研发成本最高

什么是 FPGA？

FPGA（Field-Programmable Gate Array） — 数百万 CLB/LUT，用 Verilog/VHDL 等 布线 成专用 硬件逻辑电路，非 串行执行软件。

text
        ┌─ 路径 A：Eth 头解析 ─┐
NIC ────┼─ 路径 B：IP/UDP ────┼──► 策略触发 ──► TX
        └─ 路径 C：FAST 解码 ─┘
              （同一时钟周期并行）

极致优势

维度FPGACPU 软件
并行物理级多路径 同周期线程/核 · 调度开销
确定性固定状态序列 · 无 cache miss 波动分支预测 · TLB · Jitter
OS无 OS / 线程 / IRQsyscall · 上下文切换

T2T 量级： <500 ns（书中目标）。

系统中的应用

顶尖 HFT 将以下逻辑 烧录至网卡/旁路 FPGA：

下沉模块说明
L2–L4 栈Ethernet · IP · UDP
行情解析FAST / ITCH / SBE 等
轻量执行简单 trigger · 预置订单模板

数据路径： 网卡进 → FPGA 处理 → 网卡出 — 最小化 CPU 介入。

→ 软件对照：Ch9 Bypass · Ch6 包路径

代价与风险

代价说明
硬件贵板卡 + 开发工具链
开发难时序收敛 · 仿真 · 与软件联调
逻辑复杂度上限难 承载复杂 ML/统计模型
Bug 灾难纳秒级错误可在 风控反应前 造成巨额亏损

工程原则： FPGA 负责 确定性、可形式化验证 的窄路径；复杂策略仍留 CPU 侧 或 软+硬协同。

比特币等数字资产崛起 → 传统 HFT 技术大量迁入。供需法则类似，微观结构独特。

特征HFT 含义

永续合约与资金费率

概念说明
Perpetual futures无交割日 · 可无限持仓
Funding rates定期 多↔空 资金转移 — 迫使永续价 锚定现货
HFT 机会基差 / 资金费率套利 · 跨所统计套利

CEX vs DEX

类型代表HFT 适用性

DEXUniSwap 等链上确认秒–天 · 不适合 经典 HFT
