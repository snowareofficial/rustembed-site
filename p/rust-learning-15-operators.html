一元操作符详表

操作符操作符名说明
-取负专门用于数值类型
*解引用和 Deref / DerefMut 这个 trait 关联密切，类似于 C 语言里的指针取值
!取反对数字类型使用时，会将每一位全部置反；例：!1u8 结果为 254u8
&借用向所有者租借只读使用权，生成不可变引用
&mut借用向所有者租借读写使用权，生成可变引用

关于"借用不是所有权的转移"：

  • &T / &mut T 是胖指针：长度固定（与平台指针同宽）、不夺走所有权，作用域结束自动解租。
  • 同一数据同一时刻只能有一个 &mut T（排他写），或任意多个 &T（共享读）。这是借用检查器（borrow checker）的核心约束。
  • * 解引用之所以重要，是因为 &T -> T 的转换会自动调用 Deref::deref(&T) -> &U；Box<T>、Rc<T>、String 等都实现 Deref，所以 (*my_box).field 可以直接写成 my_box.field。

位运算操作符

操作符操作符名说明
&与操作实现了 std::ops::BitAnd
``或操作
^异或实现了 std::ops::BitXor
<<左移运算符实现了 std::ops::Shl

  • 位运算在有/无符号整型上语义不同：算术（带符号）右移是 shr，但左移统一按逻辑移位（高位丢、低位补 0）。调试时要看清楚。
  • & / | / ^ 既是按位算符又是短路布尔算符（仅 bool）：false | true 不短路，false || true 短路。
  • 跟算术运算一样，移位也有 5 种策略（checked_shl / wrapping_shl / saturating_shl / overflowing_shl / 裸 <<）；32 位 u32 左移 ≥32 即未定义行为，但 wrapping_shl 会按模 N 自动回卷到合法位置。
  • 移位算符的实现 / 重载走 trait BitAnd / BitOr / BitXor / Shl / Shr，可与自定义结构体配合使用。

比较运算符

操作符操作符名说明
==等于实现了 std::cmp::PartialEq
!=不等于实现了 std::cmp::PartialEq
<小于实现了 std::cmp::PartialOrd
<=小于或等于实现了 std::cmp::PartialOrd
>大于实现了 std::cmp::PartialOrd
>=大于或等于实现了 std::cmp::PartialOrd
  • PartialEq 与 Eq 不同：相等是"部分相等"（可以与 NaN 自反但 NaN != NaN），Eq 表示全等（等价关系 + 自反）。自定义类型用 derive(PartialEq) 即可；要求等价关系的额外写 derive(Eq)。
  • PartialOrd 与 Ord 类似：PartialOrd 允 NaN-style 不可比；Ord 是全序。常用 derive(PartialOrd, Ord)。
  • Rust 写 == / != / < / > 这些算符时，编译器都会自动引用相应 trait 里的方法（eq、lt、gt 等），所以只要 derive 或 impl 一次，整个类型就都能用了。

这些 trait 全在 std::ops / std::cmp 里，实现对应 trait 即可让自定义类型也用运算符：

实现 PartialEq 自动得到 == 与 !=（Rust 写 == 自动 deref 到 PartialEq::eq）；PartialOrd 给 derive(PartialOrd, Ord) 即可。完整示例见 src/Chapter4/impl代码块.rs 里的 impl Mul for Point { ... }。

rust
use std::ops::Add;
struct Point { x: i32, y: i32 }
impl Add for Point {
    type Output = Point;
    fn add(self, other: Point) -> Point { Point { x: self.x + other.x, y: self.y + other.y } }
}
