栈（stack）和堆（heap）是 Rust 程序运行时的两个主存区域，理解它们的差异对后面所有内容都至关重要。

区域特点典型数据
栈LIFO；连续；分配/释放只是移动指针；大小必须编译期确定标量、&T、长度固定数组 [T; N]、结构体局部变量、函数帧
堆任意顺序；分散；分配/释放要走分配器；大小可运行时决定String、Vec<T>、Box<T>、哈希表、树节点

关键规律

  1. 凡是"长度不写进类型"的，几乎一定在堆上；长度能写进类型的，几乎都在栈上。
  2. 引用 &T / &mut T 自身始终是栈上胖指针；它指向的数据可能在栈上，也可能跨过堆边界。
  3. Copy 类型按位复制，复制成本 O(n) 仅与元素数有关，不区分栈/堆；非 Copy 类型 let b = a; 是移动语义，堆上原对象所有权随之转移。

字符串 vs 切片

latex
let s: String = "hello".to_string();   // 堆区数据
let r: &str   = &s;                   // 栈上胖指针 (ptr, len, cap of s)
let r2: &str  = "literal";            // 栈上胖指针，指向常量段

栈帧里 r 与 r2 大小相同（24 字节，胖指针 + 字面量元数据），但指向的内存区域完全不同：r 指向堆，r2 指向只读常量段。理解"指针在栈 vs 数据在堆"是后续字符串、Vec、引用的根。
