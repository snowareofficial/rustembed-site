## 这是什么

「能力与合作」是群友**自愿登记**的黄页：成员把自己可供合作的能力（设计、审查、咨询、小批量制作等）写成条目，放在站点上展示。

它的性质必须一开始就说清：

- **本站只做信息展示**：不参与交易、不担保、不抽成、不经手资金、不介入纠纷；
- 条目由 `owner` 字段对应的成员**本人提供并自负其责**，不代表本站对任何个人或服务的认可或背书；
- 联系方式只能引用成员档案（`content/members/<id>.sml` 的 `links`）中本人授权公开的字段，本站不代收、不新收集任何个人信息；
- 站点默认许可为 **CC BY-NC-SA 4.0（非商业）**，黄页条目同样适用；条目本身不构成商业授权，商用需与当事人另行约定；
- 本站**没有**支付、订单、撮合、站内私信、账号体系中的任何一个；谈合作、谈价钱、结算，全部在站外由双方自行完成。

## 收录标准

同时满足以下条件的条目才会被保留：

1. `owner` 是已建档成员，且条目经本人同意（自己提 PR，或托管理代投并确认）；
2. 内容只谈技术能力与合作方向，不夹带广告、拉客、返利、拉人头；
3. `contact` 只引用成员档案 `links` 里已公开的键（`blog` / `homepage` / `github` / `gitee` / `email`）；
4. 字段按契约 `Service` 填全（`name` / `owner` / `skills` / `contact` / `status` / `updated`），构建校验通过；
5. 不涉及违法、侵权、危害他人权益的内容。

## 审核项（管理员合并前逐条看）

| 维度 | 看什么 |
|---|---|
| 身份 | `owner` 是否本人、是否同意上架 |
| 联系方式 | 是否只用了本人已公开的 `links` 字段；有无夹带新的私人联系方式 |
| 表述 | 有无夸大、担保性承诺（「保证通过」「百分百」）、与他人比较的贬损性说法 |
| 费用 | `rate` 是自由文本；只要求写清「谁向谁、按什么付」，本站不经手 |
| 状态 | `status` 如实（`active` / `paused`）；长期暂停的条目会被提醒或合并下架 |
| 更新 | `updated` 随内容变动维护，避免访客看到过期信息 |

## 下架

黄页条目与文章走同一套「下架与申诉制度」（见「下架与申诉制度」页）：

- **管理员可先行下架、后说明**：仅限泄露个人信息、未授权转载、严重失实、夹带恶意文件四类情形；下架时必须在 PR 或群里写明**哪条、为什么、谁决定的**；
- **本人随时可下架自己的条目**：提 PR 改 `status: paused` 或删文件，或在群里告知任一管理员，无需理由、不得拖延；恢复同样说一声即可；
- 条目信息过期（`updated` 超过一年且无法联系到本人）时，管理员会先提醒，联系不上则按 `paused` 处理。

## 申诉入口

- 渠道：群里 @ 任意管理员，或提 Issue（标签 `制度建议`）；
- 时限：管理员 **2 个工作日内**回应；
- 复核：由未参与原决定的管理员复核；分歧时按「角色与权限制度」的决策方式处理（两名以上管理员同意，必要时群主裁决）；
- 每次下架与申诉都在 Issue 留档：时间、条目、理由、决定人、结果，记录不删除。

## 本站明确不做的事

不设计、不提供、不计划：支付与收款、订单与合同、需求撮合、站内私信、账号体系。
黄页只是「一块谁都可以看的公告板」，其余一律不归本站管。
