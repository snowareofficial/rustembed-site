# 写作台 · 全功能交互逻辑

> 纯文字规格：每个功能"从哪进、发生什么、状态怎么变、失败怎么办"。
> 与 `docs/gui-mock/` 的视觉稿、`docs/archive/gui/GUI-IMPLEMENT-PROMPT.md` 的实现约束配套。

## A. 启动

1. 用户执行 `rec-blog`（或桌面图标）。
2. 启动器定位引擎目录：`--site` > `REC_BLOG_SITE` > `~/.local/share/rec-blog/site`。
   - 不存在 → 显示"首次设置"窗口：`git clone --depth 1 gitee.com/rustembed/site`，带进度与取消；
   - clone 失败 → 显示人话错误 + 手动下载地址；**不进入主界面**。
3. 检查 `python3 >= 3.11`；不满足 → 弹窗说明安装方式，退出。
4. 拉起 `python3 engine/gui.py --port 0 --token <随机>`，读 stdout 收到 `GUI_PORT=`。
   - 超时/崩溃 → 显示 stderr 尾部 + [重试] [打开日志]。
5. 启动本地 HTTP 服务（127.0.0.1 随机端口）；有 Tauri 则开窗口，否则开默认浏览器。
6. 前端加载：`GET /api/types` + `GET /api/tree` + `GET /api/status`。
   - 树/状态失败 → 顶部横幅"引擎未就绪 [重试]"，编辑区禁用。

## B. 登录 / 登出 / 清除痕迹

**未登录**：可浏览、新建、编辑、保存、预览、校验；「提交 PR」「删除」置灰，hover 提示"登录后可用"。

**登录**：
1. 点顶栏头像/设置 → 登录页（或首次点「提交 PR」时弹出）。
2. 输入 Gitee 令牌；选择保存方式：
   - 记住（系统钥匙串）：写钥匙串，失败则提示并退回"仅本次会话"；
   - 仅本次会话：只放内存。
3. 点登录 → Rust 调 Gitee `GET /user` 验证：
   - 成功 → 顶栏显示用户名；登录态生效；
   - 401/403 → 字段下方红字"令牌无效或权限不足"，不保存；
   - 网络失败 → "无法连接 Gitee，可稍后重试"，不保存。
4. 明文永不落盘：配置文件、日志、URL、剪贴板历史都不出现 token。

**登出**：清内存 token；钥匙串条目保留（除非选择"登出并清除"）。

**清除登录痕迹**（设置页）：
1. 点击 → 弹确认，列出将清理项：钥匙串 token、最近文件、预览/构建缓存、日志、（可选）剪贴板。
2. 确认 → 逐项执行，返回结果列表；失败项单独提示。
3. 注明"git 自身保存的凭证不在本 App 管辖范围"。

## C. 内容树

- **加载**：按类型分组（文章按年份、草稿单独一组、词条/成员/项目/资源/周报/文档/契约）。
- **搜索**：输入即过滤（标题、路径、标签）；无结果时显示"没有匹配项"。
- **选中**：单击打开文件；当前项左侧赭红竖线 + 加粗。
- **标记**：来自 `git status` 的 `M/U/D` 小徽标；草稿有"草稿"角标。
- **折叠**：分组可折叠；左栏整体可收起（顶栏/面板头按钮），状态持久化。
- **右键菜单**：打开、重命名、转草稿、复制站内链接、删除（仅管理员）。
- **键盘**：↑↓ 移动，Enter 打开，Delete 删除（管理员，二次确认），Ctrl+F 聚焦搜索。
- **刷新**：保存/新建/删除/切分支后自动刷新 `tree + status`；也可手动刷新。

## D. 打开与编辑

1. 打开 → `GET /api/doc`；记录文件内容 hash（`dirty=false`）。
2. 标题行显示文件名/路径；元数据默认收起为一条摘要；右栏显示"预览待生成"。
3. 输入 → `dirty=true`：标题前出现圆点，状态栏"未保存"；树项若已存在则不变（保存后才变 M）。
4. **保存**（Ctrl+S / 顶栏确认写入）：
   - 先 `POST /api/validate`；有错 → 字段旁红字，不写文件，保持 dirty；
   - 无错 → `PUT /api/doc`（UTF-8 无 BOM、LF、末尾换行）；
   - 成功 → 更新 hash、dirty=false、状态栏"已保存 · 改动 N"、树刷新；
   - 失败（磁盘/权限）→ 顶部错误 + 保留内容。
5. **外部改动检测**：保存前比对磁盘 hash；若被外部改过 → 弹窗"文件已被外部修改"：
   - [重新加载] 丢弃当前编辑；[覆盖] 二次确认后写；[取消] 留在编辑器。
6. **切换/关闭**：dirty 时弹"保存 / 放弃 / 取消"；放弃需二次确认。
7. **自动保存**（设置，默认关）：停止输入 2 秒后按上面流程保存；校验失败时不自动重试，转为提示。

## E. 元数据（契约表单）

- 默认收起，显示摘要：`作者 · 日期 · 标签 · 导图开/关`。
- 点开：字段由契约生成（类型、必填、枚举、默认值）；标签为 chips（可删/加）；`map/series` 可选。
- 修改字段 → 标记 dirty；字段失焦时做轻量校验（必填/格式），完整校验在保存时。
- 字段错误定位到具体控件；摘要行同步更新。
- 不支持/未知字段：显示"未知字段（保留原值）"，保存时原样保留，不丢内容。

## F. 正文编辑

- Markdown 为默认；SML 文件可切"原文"，块编辑为后续（M2）。
- 工具条在编辑器内部：粗体/斜体/行内代码/链接/图片/视频/公式/列表/表格/引用。
- 「插入」菜单：标题、附件、分割线、面板、步骤、提示、图集、词条（SML 结构化块）。
- 图片：拖入正文 → 上传到 `assets/`（同名去重）→ 插入 `![](assets/…)`；失败提示且不插入。
- 公式：插入 `$...$` / `$$...$$` 模板，光标落在中间。
- 表格/列表：插入模板；多行选中可切换列表。
- 快捷键：Ctrl+B/I、Ctrl+K 链接、Ctrl+S 保存、Ctrl+P 预览、Ctrl+Enter 提交 PR。
- 编辑器内不自动预览（除非设置改"自动"）；状态栏实时字数。

## G. 预览

1. 点顶栏「预览」（Ctrl+P）→ 右栏状态"生成中"。
2. `POST /api/preview`（当前未保存内容）→ 返回 `html/toc/words`。
3. 成功 → 右栏渲染，状态"已生成 · 14:32"；失败 → 右栏显示错误 tail + [重试]。
4. 修改内容后状态回到"待生成"（不自动渲染）。
5. 预览与构建同源，避免"预览好看、线上不同"。

## H. 新建

1. 左树「+ 新建」→ 弹层。
2. 选类型（文章/词条/成员/项目/资源/周报/文档）→ 字段：标题、slug、作者、标签、草稿。
3. 路径预览随输入实时更新（文章：`posts/<年>/[系列/]<slug>/index.md`，无系列时省略该层）。
4. slug 规则：小写字母/数字/连字符；重复/非法 → 红色提示，禁止提交。
5. 创建 → `POST /api/new` 写模板 → 自动打开编辑器（dirty=true，首次保存落盘）。
6. 失败 → 保留弹层与输入，显示错误。

## I. 删除

- 入口：右键菜单 / Delete 键（选中树项）。
- 作者：只有「转草稿」；管理员：显示「删除…」。
- 删除流程：确认框（文件名、将 `git rm`、可在 PR 合并前撤回）→ `POST /api/delete`。
- 成功 → 树刷新、状态栏"改动 1"；失败 → 错误提示，不删。
- 不做物理删除；git 历史可恢复。

## J. 草稿

- `draft: true` 写在元数据；保存后移入"草稿"组。
- 构建跳过（站点/搜索/RSS 都不出现）。
- 取消勾选并保存 → 回到正常分组，参与构建。
- 草稿可删除（作者可删自己的草稿，二次确认）。

## K. 资源与附件

1. 编辑器「插入 → 附件」→ 资源选择弹层。
2. 弹层：搜索、类型/文件夹筛选；每行显示资源名、类型、文件夹、提取码 chip。
3. 点提取码 chip → 写剪贴板 + toast"已复制提取码"；失败 → 显示明文供手动复制。
4. 选中资源 → 底部显示已选（名称/链接/提取码/资源 id）。
5. 两种插入：
   - **引用资源 id**（默认）：附件字段 `resource: <id>`；资源更新后附件跟随；
   - **复制为独立附件**：写入当时的 name/url/code，之后不跟随。
6. 插入后编辑器出现附件条目；右侧检查器/附件列表显示渠道与提取码。
7. 删除附件：条目右键/删除按钮 → 从 `attachments` 移除（dirty）。

## L. 改动跟踪

- 状态栏："改动 N · 未提交"；树项 `M/U/D` 徽标。
- 来源：`GET /api/status`（`git status --porcelain`），保存/新建/删除/刷新后更新。
- 只写文件、不自动 commit；提交由 PR 流程负责。
- 冲突：pull/PR 前要求工作区干净；有冲突 → 停止并列出文件，不自动解决。

## M. 提交 PR

1. 点「提交 PR」：
   - 未登录 → 先弹登录；登录后继续；
   - 工作区无改动 → 提示"没有可提交的改动"。
2. 弹层：
   - 改动文件列表（默认全选，可取消勾选）；
   - 分支名（默认 `post/<slug>-<yyyymmddHHMM>`，可改；已存在则加后缀）；
   - 提交信息（按类型生成，可改）；
   - PR 标题/描述（自动带：类型、文件列表、契约与构建结果）；
   - 审核人（来自站点配置，可增删）。
3. 确认 → 状态"提交中"：
   - `git checkout -b` → `git add` → `git commit` → `git push origin <branch>`；
   - Gitee API 建 PR（head/base/title/body/assignees）；
   - 成功 → 显示 PR 链接、分支、审核人；状态栏"已提交 PR · 等待审核"；
   - push 成功但 PR 失败 → 保留分支，给 compare 链接 + 命令；
   - 失败（权限/网络/冲突）→ 明确错误，不重试、不 force、不改历史。
4. 永不推 master、永不 `--force`；分支保护由平台执行。

## N. 设置

- 入口：顶栏齿轮。
- 分组：账户与安全 / 外观 / 编辑 / 资源与附件 / 关于。
- 外观、编辑、资源类修改**即时生效**并持久化到本地配置（不含 token）。
- 账户类：登录状态、令牌存放位置（只读）、退出登录、清除痕迹。
- 关于：版本、引擎 commit、运行方式（Web/Tauri）。

## O. 错误与边界

| 场景 | 行为 |
|---|---|
| Python 缺失/版本低 | 启动前拦截，给安装说明 |
| 引擎崩溃 | 顶部横幅"引擎已停止 [重启]"，编辑区只读防丢内容 |
| 端口占用 | 自动重试随机端口；仍失败则报错 |
| 契约错误 | 字段级红字，保存不落盘 |
| 路径越界 | 403，前端提示"非法路径" |
| 网络断开 | 顶部"离线"横幅；编辑/保存/预览可用，PR 不可用 |
| token 过期 | 提示重新登录，不静默失败 |
| 文件被外部改 | 保存前弹重载/覆盖 |
| slug 冲突 | 新建弹层内提示，不创建 |
| 图片超限 | 提示大小上限，不插入 |

## P. 状态机（简）

```
启动 → 未登录 ⇄ 已登录
        │            │
        └─ 树/编辑器 ─┘
编辑器: 干净 → 脏 → 保存中 → 干净
              └→ 校验失败（脏）
预览: 待生成 → 生成中 → 已生成 / 失败
PR: 空闲 → 提交中 → 成功（PR 链接）/ 失败（命令+链接）
```
